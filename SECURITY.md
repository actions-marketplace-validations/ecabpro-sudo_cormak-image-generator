# Security

Report security issues privately through https://cormak.app/contact rather than
posting tokens, signed URLs, private prompts, or generated files in an issue.
If a Cormak token may have been exposed, revoke its connection in Cormak and
replace the environment secret.

The validation scripts use synthetic responses. Only copy the generation
workflows after configuring the protected environment described in
[CONNECTION.md]. Please report vulnerable versions with the exact commit SHA.
